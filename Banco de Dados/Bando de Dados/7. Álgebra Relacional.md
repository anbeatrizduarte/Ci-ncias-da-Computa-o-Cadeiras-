
#### Definição

A álgebra relacional é uma linguagem formal usada para manipular e consultar dados em bancos de dados relacionais. Ela define um conjunto de operações que recebem relações (tabelas) como entrada e produzem novas relações como saída.

Para entender um pouco melhor, é preciso voltar a conceitos básicos mostrados em [[Revisão BD1 - MER para Relacional (Exercícios).pdf]].

___
#### Operações fundamentais

As operações são divididas em:

- Operações Unárias (atuam sobre 1 tabela)
- Operações Binárias (atuam sobre 2 tabelas)

Além disso, algumas foram adaptadas da álgebra de conjuntos, como união, interseção, diferença e produto cartesiano. Enquanto outras são específicas da relacional, como seleção, projeção, divisão e renomeação.

---
##### Seleção (σ)

A **seleção** seleciona linhas que satisfazem uma condição:

```scss
σ<condicao>(R)
```

**Exemplo:**

Selecionar alunos do curso CC
```bash
σCurso='CC'(Aluno)
```

Resultado:

| RA  | Nome   | Curso |
| --- | ------ | ----- |
| 1   | Ana    | CC    |
| 3   | Carlos | CC    |

---
##### Projeção (π)

Seleciona colunas da relação.

```scss
πatributos(R)
```

**Exemplo:**

Listar apenas os nomes dos alunos:

``` scss
πNome(Aluno)
```

Resultado:

| Nome   |
| ------ |
| Ana    |
| Bruno  |
| Carlos |

___

##### Renomeação (ρ)

Renomeia o nome da relação ou de atributos

```scss
ρNovoNome(R)
ρ(A1->B1, A2->B2)(R)
```

**Exemplo:**

Criar uma tabela chamada Estudante com os mesmos dados de Aluno

```scss
ρEstudante(Aluno)
```

___

##### União (R ∪ S)

Une duas relações com mesma estrutura

**Regras:**
- mesmo número de atributos
- atributos compatíveis

**Exemplo:**

| RA  | Nome |
| --- | ---- |
| 1   | Ana  |

| RA  | Nome  |
| --- | ----- |
| 2   | Bruno |

```nginx
AlunoCC ∪ AlunoSI
```

Resultado:

| RA  | Nome  |
| --- | ----- |
| 1   | Ana   |
| 2   | Bruno |

___
##### Interseção (R ∩ S)

Retorna tuplas que estão nas duas relações

**Exemplo:**

| RA (A) |
| ------ |
| 1      |
| 2      |

| RA (B) |
| ------ |
| 2      |
| 3      |

```css
A ∩ B
```

Resultado:

| RA  |
| --- |
| 2   |

___

##### Diferença

Retorna tuplas que estão em R mas não em S

Exemplo:

```css
A - B
```

Resultado:

| RA  |
| --- |
| 1   |

___
##### Produto Cartesiano (R × S)

Combina cada tupla de R com cada tupla de S

**Exemplo:**

| RA  | Nome |
| --- | ---- |
| 1   | Ana  |

| Cod | NomeDisc   |
| --- | ---------- |
| BD  | BancoDados |

```nginx
Aluno × Disciplina
```

Resultado:

| RA  | Nome | Cod | NomeDisc   |
| --- | ---- | --- | ---------- |
| 1   | Ana  | BD  | BancoDados |

#### Tratamento de vazio

O tratamento de valores vazios (ou valores nulos) é um conceito importante tanto na álgebra relacional quanto no contexto de bancos de dados relacionais. O valor nulo indica que um determinado dado não está presente ou é desconhecido.

Nesse contexto, ele é um valor especial que representa a ausência de um dado válido. Ele não é igual a zero, nem a uma cadeia vazia ou qualquer outro valor, e, portanto, exige um tratamento especial durante as operações.

Na abordagem relacional usamos uma **lógica de três valores**. Este conceito é uma extensão da lógica booleana para lidar com valores nulos.

-  **falso** (FALSE)
-  **verdadeiro** (TRUE)
-  **desconhecido** (UNKNOWN)


##### Valor desconhecido (UNKNWON)

O terceiro valor (NULL ou desconhecido) não pode ser comparado diretamente com outros valores da mesma maneira que true ou false.

A tabela a seguir ilustra os três valores possíveis nas comparações lógicas envolvendo NULL:

| **Operação**    | **True** | **False** | **NULL** |
| --------------- | -------- | --------- | -------- |
| **True AND X**  | True     | False     | NULL     |
| **False AND X** | False    | False     | False    |
| **NULL AND X**  | NULL     | False     | NULL     |
| **True OR X**   | True     | True      | True     |
| **False OR X**  | True     | False     | NULL     |
| **NULL OR X**   | True     | NULL      | NULL     |
| **NOT True**    | False    | True      | NULL     |
| **NOT False**   | True     | True      | NULL     |
| **NOT NULL**    | NULL     | NULL      | True     |

###### Comparações com NULL

Quando você faz uma comparação entre valores que envolvem NULL, o resultado será sempre NULL (desconhecido), exceto em operações explícitas como `IS NULL` ou `IS NOT NULL`.

Por exemplo:

-  Idade > 25, onde o valor da Idade é NULL resulta em NULL (desconhecido)
-  Idade = NULL resulta em NULL. Isso é diferente de Idade <> NULL, que também retorna NULL.
-  Para saber se uma coluna é NULL, usamos `IS NULL`


Outro exemplo:

- Se nome1 e nome2 forem vazios, a comparação nome1 = nome2 resulta em NULL
- Se nome for vazio, a comparação nome1 <> 'Joao' resulta em NULL

#### Operação de junção (JOIN - ⨝)

Uma junção combina tuplas (linhas) de duas relações (tabelas) com base em uma condição que relaciona atributos (colunas) dessas tabelas. Ela é fundamental para reconstruir informações que estão distribuídas em múltiplas tabelas, uma prática comum em modelagem normalizada.

Na álgebra relacional, a junção é representada pelo símbolo:  **⨝**.


##### Junção Theta (θ-join)

É a forma mais geral de junção. Usa uma condição arbitrária (chamada θ).

```bash
R ⨝θ S
```

Onde θ pode ser =, >, <, >=, etc.

**Exemplo:**

Tabela Pessoa:

| ID  | Nome | Cidade |
| --- | ---- | ------ |
| 1   | Ana  | SP     |
| 2   | João | RJ     |

Tabela Endereço:

| ID_Pessoa | Rua        |
| --------- | ---------- |
| 1         | Rua A, 100 |
| 3         | Rua C, 300 |

**Junção com condição:**

```
Pessoa ⨝(ID = ID_Pessoa) Endereço
```

| ID  | Nome | Cidade | Rua        |
| --- | ---- | ------ | ---------- |
| 1   | Ana  | SP     | Rua A, 100 |

___

##### Junção Equijoin (junção por igualdade)

É uma caso especial da junção θ onde a condição é uma igualdade

```
R ⨝ A = B S
```

Exemplo: igual ao anterior

___

##### Junção Natural (⨝)

É a junção mais conhecida na álgebra relacional.

Ela combina automaticamente as tuplas com valores iguais em todos os atributos que possuem o mesmo nome em ambas as tabelas, e elimina colunas duplicadas.

```
R ⨝ S
```

**Exemplo:**

Usando as tabelas Pessoa, Endereço:

```
Pessoa ⨝ Endereço
```

| ID  | Nome | Cidade | Rua        |
| --- | ---- | ------ | ---------- |
| 1   | Ana  | SP     | Rua A, 100 |

___

##### Junção interna (inner join)

É equivalente à junção natural quando as colunas de junção possuem o mesmo nome.

É a junção padrão:

- só retorna tuplas que têm correspondência em ambas as tabelas

___

##### Junção externa (outer join)

As junções externas não existem formalmente na álgebra relacional clássica, mas aparecem como extensões modernas. Elas preservam tuplas mesmo quando não há correspondência.

- **Left Outer Join:** mantém TODAS as tuplas da tabela da esquerda

- **Right Outer Join:** mantém TODAS da direita

- **Full Outer Join:** mantém TODAS de ambas

Exemplo com **Left Join**:

```
Pessoa ⟕ Endereço
```

| ID  | Nome | Cidade | Rua       |
| --- | ---- | ------ | --------- |
| 1   | Ana  | SP     | Rua A,100 |
| 2   | João | RJ     | NULL      |

___

##### Resumo da utilização de cada junção


| Tipo de Junção      | Usada Quando...                                             |
| ------------------- | ----------------------------------------------------------- |
| **Natural**         | tabelas têm atributos com mesmo nome e relação direta       |
| **Theta**           | condição de junção é diferente de "igual"                   |
| **Equijoin**        | usa igualdade mas mantém colunas duplicadas                 |
| **Inner Join**      | queremos apenas correspondências                            |
| **Left Outer Join** | queremos todos da esquerda + correspondências da direita    |
| **Full Outer Join** | manter tudo de ambas com NULL onde não há match             |
| **Semi-join**       | queremos filtrar a esquerda mas sem trazer dados da direita |
| **Anti-join**       | queremos o que NÃO se relaciona                             |
