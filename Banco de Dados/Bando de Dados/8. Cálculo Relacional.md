
#### Sobre

O Cálculo Relacional é uma linguagem declarativa usada na teoria de bancos de dados relacionais. Em vez de especificar como obter os dados (como fazemos na Álgebra Relacional), descrevemos apenas quais dados queremos.

Existem duas variantes:

- Cálculo Relacional de Tuplas (TRC)
- Cálculo Relacional de Domínios (DRC)

___
#### Cálculo Relacional de Tuplas (TRC)

No TRC, lidamos com variáveis que representam tuplas inteiras.

A forma geral é:

```less
{ t | P(t) }
```

Onde:
- **t** é uma variável que representa tuplas
- **P(t)** é um predicado lógico (condições que a tupla deve satisfazer)


##### Exemplo

Aluno(matricula, nome, curso, idade)

| matricula | nome  | curso | idade |
| --------- | ----- | ----- | ----- |
| 101       | Ana   | CC    | 20    |
| 102       | Bruno | SI    | 22    |
| 103       | Carla | CC    | 21    |

> **Exemplo 1: Selecionar todos os alunos do curso de CC**

```nginx
{ t | Aluno(t) AND t.curso = "CC"}

// o conjunto de todas as tuplas t da tabela Aluno cujo atributo curso é igual a "CC"
```

Resultado:

- Ana
- Carla



> **Exemplo 2: Selecionar nome e idade dos alunos com idade > 20**

```nginx
{ <t.nome, t.idade> | Aluno(t) AND t.idade > 20}

// o conjunto de todas as tuplas t da tabela Aluno cujo atributo idade é maior que 20
```

| nome  | idade |
| ----- | ----- |
| Bruno | 22    |
| Carla | 21    |


> **Exemplo 3: Buscar alunos com idade igual a algum aluno do curso de SI**

```nginx
{ t | Aluno(t) AND ∃s (Aluno(s) AND s.curso = "SI" and t.idade = s.idade)}

// todas as tuplas t da tabela Aluno cuja idade seja igual à idade de algum aluno do curso SI
```

| matricula | nome  | curso | idade |
| --------- | ----- | ----- | ----- |
| 102       | Bruno | SI    | 22    |


> **Exemplo 4: Selecionar apenas nome e idade de alunos com idade > 20**

```nginx
{ <t.nome, t.idade> | Aluno(t) t.idade > 20}
```



> **Exemplo 6: Selecionar alunos que NÃO são de SI**

```nginx
{ t | Aluno(t) AND NOT(t.curso = "SI")}
```



> **Exemplo 7: Selecionar alunos que são mais velhos do que todos do curso CC**

```nginx
{ t | Aluno(t) AND ∀r (Aluno(r) AND r.curso = "CC" -> t.idade > r.idade)}
```


> **Exemplo 8: Selecionar alunos do mesmo curso que Ana**

```nginx
{t | Aluno(t) AND ∃a (Aluno(a) AND a.nome = "Ana" AND t.curso = a.curso)}
```


> Exemplo 9: Selecionar pares (nome, nome) de alunos que têm a mesma idade

```nginx
{ <t.nome, s.nome> | Aluno (t) AND Aluno(S) AND t.idade = s.idade AND t.matricula ≠ s.matricula}
```


> Exemplo 10: Selecionar alunos que têm idade dentro do intervalo [20, 21]

```nginx
{t | Aluno(t) AND t.idade >= 20 AND t.idade <= 21}
```

#### Quantificadores

##### Quantificador Existencial (∃)

O quantificador existencial indica que: "Existe pelo menos um elemento que satisfaz a condição"

**Símbolo:**     ∃x P(x)

**Leitura:**        Existe algum x tal que P(x) seja verdadeiro


**Exemplo:**

Tabela Aluno

| matricula | nome  | curso | idade |
| --------- | ----- | ----- | ----- |
| 101       | Ana   | CC    | 20    |
| 102       | Bruno | SI    | 22    |
| 103       | Carla | CC    | 21    |

>  **Queremos alunos que têm a mesma idade de algum aluno do curso SI**

```nginx
{ t | Aluno(t) AND ∃s (Aluno(s) AND s.curso = "SI" AND t.idade = s.idade)}
```

- ∃s -> "existe algum aluno s..."



>  **Queremos selecionar todos os alunos que estão no mesmo curso que algum aluno chamado Bruno**

```nginx
{ t | Aluno(t) AND ∃s (Aluno(s) AND s.nome = "Bruno" AND t.curso = s.curso )}
```

- ∃s -> "existe algum aluno s..."


##### Quantificador Universal (∀)

O quantificador universal indica que: "Todos os elementos satisfazem a condição"

**Símbolo:**     ∀x P(x)

**Símbolo:**     Para todo x, P(x) é verdadeiro


**Exemplo:**

Tabela Aluno

>  Queremos alunos com idade maior que todos os alunos do curso CC

```nginx
{ t | Aluno(t) AND ∀s (Aluno(s) AND s.curso = "CC" -> t.idade > s.idade)}
```


>  Selecionar alunos que estão no mesmo curso que todos os alunos com idade 20

```nginx
{ t | Aluno(t) AND ∀s (Aluno(s) AND s.idade = 20 -> t.curso = s.curso)}
```


##### Exemplos


>  Selecione os alunos que estão no mesmo curso que algum aluno com idade 22

```nginx
{ t | Aluno(t) AND ∃s (Aluno(s) AND s.idade = 22 AND t.curso = s.curso)}
```


>  Selecione os alunos que são mais novos que todos os alunos do curso SI

```nginx
{ t | Aluno(t) AND ∀s (Aluno(s) AND s.curso = "SI" -> t.idade < s.idade)}
```


>  Selecione os alunos cujo curso possui pelo menos um aluno mais velho que todos os alunos com idade 20

```nginx
{ t | Aluno(t) AND ∃s (Aluno(s) s.curso = t.curso AND ∀r (Aluno(r) AND r.idade = 20 -> s.idade > r.idade)) }
```


>  Selecione os alunos que têm a mesma idade de algum aluno chamado Daniel

``` nginx
{ t | Aluno(t) AND ∃s (Aluno(s) s.nome = "Daniel" AND t.idade = s.idade)}
```


>  Selecione os alunos que estão no mesmo curso que todos os alunos com idade 21

```nginx
{ t | Aluno(t) AND ∀s (Aluno(s) -> s.idade = 21 -> t.curso = s.curso)}
```

#### Relação com a Álgebra Relacional

-  **Álgebra Relacional** -> Procedural (como obter)
-  **Cálculo Relacional** -> Declarativo (o que obter)

**Exemplo:**

```nginx
// AR:

σ curso = "CC" (Aluno)

// TRC:

{ t | Aluno(t) AND t.curso = "CC"}

```
